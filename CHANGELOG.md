Changelog

All notable changes to Music Player are documented here.

[2.1.1]

Added

- 🎵 Floating Music Player bubble
- 👋 Time-based greetings
- 🎧 Soft Sounds section
- 🎵 Integrated playlist inside the floating player
- 📱 Compact player interface
- 🔊 Volume control
- ⏱️ Playback progress control
- ⏮️ Previous track control
- ⏭️ Next track control

Changed

- Redesigned the Music Player interface around a floating bubble.
- The player can now be opened and closed without leaving the floating bubble.
- Improved the visual presentation of the current song and playlist.

Preserved

- Multiple audio file selection
- Local audio playback
- Playlist management
- Automatic next-track playback
- Play / pause functionality

[2.1.0]

Added

- Basic Music Player interface
- Audio file selection
- Multiple-file playlist
- Play / pause
- Previous / next track
- Volume control
- Playback progress
- Automatic next-track playback

[1.0.0]

Initial Release

- First public release of Music Player for Acode.
